Cookie Policy

Veilux uses a limited set of browser storage tools to preserve session context, remember workspace state, and understand how visitors use key public pages.

What Is Stored

  • Session state for login and dashboard continuity.
  • Workspace preferences and local UI state on app surfaces.
  • Basic analytics and performance preferences where enabled.

Your Controls

  • You can clear browser storage at any time.
  • Deleting local storage resets workspace preferences and demo state.
  • Questions can be sent to hello@veilux.network.
